# Contexto conservado

PACK_MANIFEST.json, PACK_VALIDATION.json y SHA256SUMS.txt describen exclusivamente
el paquete original, no el producto implementado. El paquete intacto permanece en
`jencut-codex-starter-v1/`; sus archivos también se copiaron a las ubicaciones del
proyecto. Los acuerdos activos están en el AGENTS.md de la raíz. El AGENTS original
se conserva como `docs/current/STARTER_AGENTS.md` para no sobrescribirlos.

El estado vigente del software está en `docs/STATUS.md`, `progress/STATE.json` y
`progress/VERIFICATION.md`.
